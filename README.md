# 死亡细胞 · 战斗实验室

用 Godot 项目管理器导入本目录的 `project.godot`，打开项目后按 **F5** 运行主场景。也可以直接运行下面的命令。

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path /Users/yangyu/workspace/godot_pro
```

本项目使用灰盒角色和合成音效，自带的数值是可调的原型假设。测得的《死亡细胞》数据可以录入原 Excel 的「实机观察」，再与这里的试验记录对照。

## 控制

| 操作 | 按键 |
| --- | --- |
| 左右移动 | A、D 或方向键 |
| 跳跃 / 二段跳 | Space 或 W，短按低跳，长按高跳，空中再按一次 |

## 三个实验

**1 · 角色手感**  
按 Tab 切换 A「灵敏」和 B「惯性」。先向右跑到满速，再松键或按左，观察带正负号的横向速度。松键后角色会继续滑行，反向输入会先消掉原方向的速度，再向新方向加速。跑跳时会带着原有横向速度起跳，翻滚结束后也会保留余速并逐步减速。

右侧可以单独调「地面松键减速」「反向制动」和「空中松键减速」。把「空中松键减速」设为 0，角色在空中松键时会继续以当前横向速度移动，直到落地、撞墙或重新输入方向。翻滚无敌段可单独调整，只有落在翻滚时长内的部分有效。

一段跳和二段跳都可以控制高度。上升时松开跳跃键会提前减速，按住直到到达最高点会跳满当前设置的目标高度。空中松开再按可以跳第二次，落地后恢复。错过离地宽容时间后，从平台走下也可以用一次空中跳。右侧可调二段目标跳高，默认从触发位置再升约 96 px。测试落地缓冲时，先用掉二段跳，再在落地前按跳。

**2 · 战斗决策**  
对同一个近战敌人分别试着提前攻击、后撤等空挥、翻滚后反击。黄色框和抬手提示代表前摇，红色框代表有效段，后摇用青色标记。优先看受击、避伤和反击命中，备注写下当时看到了什么提示、采取了什么行动，以及结果是否符合预期。音效、命中停顿和震动可单独关闭做对照。

按 L 投出爆炸球，可以和 J 的近战攻击一起用。球会沿抛物线飞行，碰到地面、墙或角色会反弹。每次近战挥击可以击飞球一次，爆炸前可反复击球。爆炸只会伤到最后击球者的对手，刚投出时目标是敌人。右侧「副武器 · 爆炸球」可以调整爆炸延时，默认 2400 ms，从出手时开始倒计时。击球不会重置倒计时，每次场上最多有一颗球。

在右侧切到「打击反馈」，可以独立试验命中停顿、受击闪白、击退、屏幕震动、受击粒子、命中火花、挥砍残影和伤害数字。调参会重开试验并保存设置，可用「恢复反馈默认值」回到基线。近战和爆炸在实际扣血时触发受击反馈，玩家每次受击扣 1 HP，飘字显示实际扣血量。挥砍残影在攻击进入有效帧时出现，空挥和击球也能看到。命中停顿期间角色和球暂停推进，未进入受击硬直的玩家仍可缓冲输入。

玩家和敌人受击后会立刻中断攻击，硬直期间只受重力和击退影响。玩家受击时会清空动作缓冲，硬直期间按下的跳跃、翻滚、攻击和投掷都要在恢复后重新按键。

**3 · 武器差异**  
保持敌人参数与角色方案一致，按 Tab 重开并切换武器。快武器较短，出手和收招更快，攻击时可以移动。重武器距离较长，出手时锁定横向移动，默认会延长敌人的受击硬直，收招也更慢。记录前摇或后摇出手次数、平均命中距离、受击和胜负，再比较两把武器是否改变了站位和攻击时机。

| 初始武器 | 前摇 / 有效段 / 后摇 | 攻击框长度 | 攻击时移速上限 | 单击伤害 |
| --- | --- | --- | --- | --- |
| 快武器 | 100 / 85 / 190 ms | 67 px | 正常的 73% | 1 |
| 重武器 | 330 / 130 / 400 ms | 140 px | 0% | 2 |

## 记录与改动

- 右侧实时调参会重开当前试验。先填备注并点「记录到 CSV」，再切换方案。填写时战斗会暂停，按 Esc 可返回。击败敌人或玩家倒下后可以继续记录。
- 「打开记录目录」可找到 `trials.csv` 和自动保存的 `tuning.cfg`。每条 CSV 记录带有当前数值、反馈开关和实测计数，可以用 Excel 打开。避伤只统计攻击框与无敌中的角色相交的情况，走位或跳跃造成的空挥另计。
- [scripts/tuning.gd](scripts/tuning.gd) 定义初始参数与调整范围。[scripts/player.gd](scripts/player.gd) 管角色动作，[scripts/enemy.gd](scripts/enemy.gd) 管敌人状态，[scripts/lab.gd](scripts/lab.gd) 管对局和命中判定，[scripts/arena_view.gd](scripts/arena_view.gd) 管画面。右侧「恢复当前实验默认参数」会清除对应数值的本地覆盖。
